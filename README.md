# Coffee Machine CLI ☕

Консольное приложение для управления автоматической кофемашиной, написанное на Python с использованием принципов объектно-ориентированного программирования (ООП).

## 🚀 Возможности
- **Строгая инкапсуляция и валидация:** Защита ресурсов (вода, зёрна, молоко) от отрицательных значений и превышения лимитов емкости.
- **Интерактивные рецепты:** Приготовление эспрессо, американо и капучино с автоматическим списанием ингредиентов.
- **Контроль отходов:** Автоматическая блокировка машины после 5 приготовленных чашек до проведения очистки (`clean_machine`).
- **Визуализация процессов:** Текстовая анимация прогресс-бара при приготовлении кофе прямо в консоли.
- **Защита интерфейса:** Безопасный ввод команд с обработкой ошибок и исключением падений программы при нехватке ресурсов.

## 🛠 Технологии
- Python 3.x
- Модули: `time`
